# The Build Designer

This is the page where you can edit your overall domino build:

- You can add domino elements
    -  Currently, the only element available is a domino field
- You can modify elements:  Move, resize, delete
- Double-click an element to edit its domino colors
    -  Do this by by double clicking the element either on the sidebar or in the build
    -  For more information go to [Editing Dominoes](domino-editing)

Display controls available in the Build Designer:

- Pan around the build plane:  With right-click-drag mouse button
- Zoom the build plane using:
    - The middle-mouse wheel
    - The zoom in / zoom out toolbar buttons in the upper right hand side of the screen
    - The "Reset Zoom" toolbar button - to fit the entire build plane into the available window

## The Build Elements Sidebar

The sidebar shows a list of all elements in your build.

- Hover over an element in the sidebar to see a three-dot menu
    - Use this menu to delete the element or edit its properties
    - For an element that holds dominoes, this menu also prints its
      [build plans](build-plans) — the layout and the sort plan

## The Build Plane

The build plane is the floor space of your build. It can hold multiple elements, such as multiple domino fields.

You can edit the size of the build plane by:

1. Hover over the "Build Plane" element in the sidebar
2. Clicking on the three-dot menu that appears to the right
3. Select "Properties"
4. Specify the new size of the build plane

## Add elements to your build

Use the "New" button in the toolbar to add a new element to the build plane

-  Currently, the only element available is a "Domino Field" element

## Edit elements in your build

You can modify the elements currently in your build:

First, click on an element to select it. This can be done by clicking on the element as it appears on the build plane, or by clicking the element in the list of elements in the sidebar.

Once the element is selected, you can:

-  Click-drag the element to move it
-  Press DEL to delete the element
-  Click-drag on an element's handle (the blue squares) to resize it

## Editing domino colors

Double-click on an element to edit its colors.

You can double-click on the element on the build plane, or in the element list sidebar.
