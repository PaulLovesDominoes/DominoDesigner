# Linking example

This is a second topic, reached by clicking a link from [home](home).

A link's `href` is just the target file's name without `.md` (its topic id).
Anything that isn't a known topic id — like an `https://` URL — opens as a
normal external link instead.

This file is a placeholder to prove the mechanism works end to end; delete it
once real help topics start linking to each other.
