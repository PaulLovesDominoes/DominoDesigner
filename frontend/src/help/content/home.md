# Help

Help is still under construction.

But for now, what you most need to know is this:
-  Left mouse:  Executes the tool bar function
    - Typically select
-  Right mouse:  Drag (e.g. pan) the window around
-  Mouse wheel:  Zoom

For creating more help later:

To add help for a screen, create a new file under `help/content/`, then map the
screen to its topic id in `help/registry.ts`.

Links between topics stay inside this panel — see the [linking example](example)
topic for how that works.
